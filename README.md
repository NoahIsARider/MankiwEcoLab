# 经济学原理模拟系统 (Economics Principles Simulation)

基于曼昆《经济学原理》的经济系统模拟项目。

## 项目简介

本项目通过计算机模拟展示微观经济学和宏观经济学的核心原理，包括：

- **供需均衡**：模拟市场中供给和需求如何决定价格
- **边际效用递减**：消费者决策基于边际效用最大化
- **生产者行为**：企业基于边际成本和边际收益做出生产决策
- **价格发现机制**：市场如何通过价格信号协调资源配置
- **均衡状态**：经济系统如何达到均衡

## 核心功能

1. **经济主体模拟**
   - 消费者：具有效用函数和预算约束
   - 生产者：具有生产函数和成本结构
   
2. **市场机制**
   - 双边拍卖市场
   - 价格调整机制
   - 供需匹配算法

3. **可视化分析**
   - 供需曲线动态变化
   - 价格收敛过程
   - 市场效率指标
   - 消费者剩余和生产者剩余

## 理论基础

### 消费者理论
- 效用函数：U(x) = α * ln(x + 1)
- 预算约束：p * x ≤ income
- 需求函数：基于效用最大化

### 生产者理论
- 生产函数：Q = A * L^α * K^β
- 成本函数：TC = FC + VC(Q)
- 供给函数：基于利润最大化

### 市场均衡
- 供给 = 需求时的均衡价格
- 通过迭代调整达到均衡
- 市场出清机制
